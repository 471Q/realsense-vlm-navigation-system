Literature Review Checklist — Smart-Walker (Prioritized)
Date: 2025-11-08

MUST (essential — include and discuss early)
1. RGB-D Perception and RealSense Depth Characteristics
   - Topics: depth sensing principles, validity masks, measurement noise, reflective surface failure modes.
   - Note: Include RealSense-specific constraints (range, resolution) and best-practices for masking and unit conversion.

2. Conservative Distance Estimation (Lower-band median, ROI sampling)
   - Topics: robust statistics (median, trimmed percentiles), lower-band sampling for ground-proximate distance.
   - Note: Argue why lower-band reduces optimistic estimates and list fallback chains.

3. Object Detection for Assistive Mobility (YOLO family / YOLOv8)
   - Topics: single-stage detectors, NMS, confidence calibration, multi-scale detection, latency/accuracy trade-offs.
   - Note: Emphasize small-model variants (yolov8n) for edge deployment and preprocessing (letterbox, fp16).

4. Vision-Language Models (VLMs) for Constrained Captioning (Qwen2.5-VL, LLaVA)
   - Topics: encoder-decoder/decoder-only VLM architectures, visual projection/bridging layers, instruction tuning.
   - Note: Focus on formats for constrained outputs (one-sentence, token vocab) and model selection rationale.

5. Safety-Critical System Design and Policy Injection
   - Topics: deterministic advisory/suggestion layers, policy injection, grammar constraints, contradiction guards.
   - Note: Position VLM as renderer only, with upstream deterministic checks to reduce hallucination risk.

6. Edge Deployment and Quantization (bitsandbytes, 4-bit, fp16)
   - Topics: post-training quantization, memory/latency impacts, CPU vs GPU trade-offs, toolkit options.
   - Note: Practical guidance for running 3B models on CPUs and when to prefer GPU/quantization.

7. Benchmarking Methodology for Multimodal Systems
   - Topics: latency/p50, throughput (tok/s), memory profiling (GPU peak, RSS), reproducible runs, warmup.
   - Note: Describe microbenchmarks vs end-to-end FPS and config dimensions (device, precision, runs).

8. Lane-based Free-space Reasoning and Discretization
   - Topics: lane partitioning, ROI selection, median per lane, threshold calibration for clear vs blocked.
   - Note: Include human-centred lane semantics and mapping from lane-clear vectors to suggestions.

9. Robustness and Temporal Filtering (EMA, debouncing)
   - Topics: EMA smoothing, debounce windows, handling sparse depth, UNKNOWN-as-BLOCKED policies.
   - Note: Show empirically how smoothing reduces oscillation and false guidance flips.

10. Human Factors and Interface Constraints for Assistive Devices
    - Topics: single-sentence communication, cognitive load, lane naming, acceptability of suggestions.
    - Note: Cite guidance on minimal cognitive burden and wording clarity for mobility aids.

SHOULD (important — support arguments and methods)
11. Uncertainty Quantification and Probabilistic Methods
    - Topics: variance, IQR, confidence intervals for depth/detection; how to communicate uncertainty.

12. Dataset Collection and Annotation for Mobility Scenes
    - Topics: scenario coverage, annotation strategies for hazards and lane labels, privacy/ethics.

13. Image Encoding and Compression Strategies
    - Topics: JPEG/PNG encoding trade-offs, image size choices (224–336), effect on VLM grounding.

14. Prompt Engineering and Output Normalization Techniques
    - Topics: system prompts, allowed token lists, post-processing (strip distances, coerce tokens).

15. Related Assistive Navigation Systems and Benchmarks
    - Topics: prior smart-walker or mobility-assist systems, standard evaluation tasks and metrics.

OPTIONAL (nice-to-have / broader context)
16. Advanced VLMs and Multi-Modal Retrieval
    - Topics: larger models, retrieval-augmented generation, grounding with external knowledge.

17. Formal Verification of Decision Logic
    - Topics: invariants for suggestion mapping, proofs for safety-critical transitions.

18. Edge Hardware and Power Management
    - Topics: runtime power, thermal throttling, scheduling perception vs generation workloads.

19. Multi-sensor Fusion (LiDAR, IMU)
    - Topics: benefit of additional sensors for robustness and redundancy; fusion architectures.

20. Legal, Ethical and Accessibility Considerations
    - Topics: liability, user consent, accessibility standards and inclusivity of language.
