QWEN VLM-BASED REALSENSE GUIDANCE SYSTEM: TECHNICAL EXPLANATION (PhD ORIENTED)
==========================================================================

1. SYSTEM CONTEXT OVERVIEW
--------------------------
This solution implements an embodied perception-and-guidance pipeline that ingests RGB-D frames from an Intel RealSense sensor, performs object detection (YOLOv8 nano) and structured depth analysis, and synthesizes a single-sentence, human-readable safety caption plus an explicit movement suggestion using a Vision-Language Model (Qwen2.5-VL 3B Instruct) hosted through a llama.cpp/OpenAI-compatible server. It targets assisted mobility scenarios ("smart walker") where rapid, cognitively lightweight guidance is required. The VLM acts as a linguistic post-processor over deterministic spatial facts, not as an unconstrained generator, reducing hallucination risk and ensuring safety-aligned outputs.

2. HIGH-LEVEL ARCHITECTURE
--------------------------
Pipeline stages:
  (a) Capture Thread: Streams synchronized color + depth frames from RealSense at configured resolution/FPS.
  (b) Inference Thread: Runs YOLO detection on RGB, associates depth values, computes conservative per-object distance estimates (lower-bbox band median), assembles structured facts (object label, distance_m, lateral bearing, lane occupancy).
  (c) Lane Modeling: Collapses the scene into three macro longitudinal traversal bands: LEFT / MID / RIGHT. For each band, depth samples from a corridor region-of-interest are aggregated; a robust median depth per band is computed.
  (d) Clearance & Suggestion Logic: Applies a threshold (clear_threshold_m) to each band median to classify lanes as CLEAR vs BLOCKED. Derives an action Suggest token (continue, left, right, mid-left, mid-right, left-right, stay-left/right, back) via deterministic rules over the set of clear lanes.
  (e) Risk Assessment: Converts object/hazard proximities into a qualitative advisory level: SAFE, CAUTION, or STOP using distance bins and lane conflicts.
  (f) VLM Worker: Packages distilled facts (objects + lane clearance + advisory intent) into a constrained prompt. Qwen2.5-VL receives the current RGB image (with multi-encoding fallbacks) plus textual structured facts and returns a caption. Post-processing enforces token normalization, mirroring semantics (optional), and safety constraints.
  (g) Caption Finalization: Ensures a single sentence with explicit Suggest token. SAFE captions suppress distances; CAUTION/STOP include obstacle names and conservative distances. Humanization removes technical lane jargon, yielding accessible phrasing.
  (h) Overlay & Badge: Visualization layer renders lane bands (debug mode) and a top-right SAFE PATH badge reflecting computed Suggest.

3. DATA FLOW & MODULE INTERFACES
--------------------------------
Input: RealSense RGB-D frame (color_image, depth_frame).
Intermediate Structures:
  - detections: list[{label, bbox(x1,y1,x2,y2), distance_m, bearing_deg}]
  - lane_depths: dict{left: median_depth_m, mid: median_depth_m, right: median_depth_m}
  - lane_clear: dict{left: bool, mid: bool, right: bool}
  - hazards: filtered detections within critical distance or occupying chosen lane
  - advisory_level: enum{SAFE, CAUTION, STOP}
Output: caption (string, single sentence), suggest (string token), badge label.

Contracts:
  - distance_m: non-negative float, NaN replaced by fallback median or sentinel.
  - suggest must be one of allowed tokens after normalization.
  - caption must contain exactly one terminating period (or punctuation equivalent) and reflect advisory semantics.

4. ALGORITHMIC DETAILS
----------------------
4.1 Distance Estimation (Lower-Band Median)
  - Motivation: Depth at the lower portion of an object's bounding box correlates with ground-contact proximity, reducing optimistic error from upper surfaces.
  - Procedure: Extract depth pixels in bottom ~25-33% vertical band of bbox; remove zeros; compute median. Fallback chain: lower-band median -> full-box median -> nearest nonzero sample -> default large distance sentinel.
  - Safety Impact: Produces conservative (never understated) object distances, leading to earlier CAUTION/STOP advisories.

4.2 Lane Depth Aggregation
  - Region-of-interest horizontally partitioned into three equal-width bands.
  - For each band: sample depth subset, discard invalid (0 / > max_range), compute robust median. Outlier rejection (implicit via median) stabilizes under speckle noise.
  - Complexity: O(N) over sampled pixels; bounded by ROI size rather than full frame.

4.3 Clearance Classification
  - clear_threshold_m (e.g., 1.8 m) selects cutoff for free traversal.
  - Lane state: CLEAR if median >= threshold; else BLOCKED. Parameterizable for corridor width changes.
  - Future extension: adaptive threshold scaled by running percentile of mid lane depth.

4.4 Suggestion Derivation Logic
  Deterministic rule-set:
   - 0 CLEAR: back
   - 1 CLEAR: that lane (mid -> continue; side -> left/right)
   - 2 CLEAR: lane pairs mapped to mid-left / mid-right / left-right to express composite availability
   - 3 CLEAR: continue (mid precedence conveys straight path)
   - Persistence: Optionally memory_list can prevent oscillations (not fully exploited yet).

4.5 Advisory Level
  - Hazard distances bucketed: near (< threshold * alpha), medium, far.
  - STOP if nearest hazard below hard floor (e.g., < 0.6 m) or all lanes blocked.
  - CAUTION if at least one traversal path exists but a hazard within caution radius intersects or borders intended lane.
  - SAFE otherwise.

4.6 Caption Synthesis & Normalization
  - Input facts become structured text; VLM constrained by system prompt listing allowed Suggest tokens and one-sentence requirement.
  - Post-processing steps:
     1. Parse model output; extract tokens; sanitize casing/punctuation.
     2. Enforce allowed Suggest set; fallback to continue if invalid during SAFE, or back during STOP.
     3. Remove contradictory STOP+continue patterns by precedence rules.
     4. Humanize lane descriptors ("left side" vs internal token) for readability.
     5. Inject obstacle details only for CAUTION/STOP; remove distance phrases for SAFE.
     6. Guarantee single sentence—condense multiple clauses via commas; final period enforced.

4.7 Mirroring Semantics
  - When --mirror_view active: left/right lanes swapped in facts prior to Suggest calculation, ensuring UI alignment with reversed video orientation.
  - Caption humanization respects mirrored mapping, avoiding cognitive dissonance for operator.

4.8 Robustness Measures
  - Multi-encoding fallback for image (e.g., JPEG, PNG resizing) to avoid sporadic VLM processing failures.
  - Median-based depth reduces susceptibility to isolated sensor zeros.
  - Deterministic pre-VLM reasoning minimizes reliance on generative model for safety-critical logic.

5. DESIGN RATIONALE
-------------------
5.1 3-Band vs 5-Sector
  - Initial five-sector prototype improved granularity but increased linguistic complexity and cognitive load; user feedback favored simpler LEFT/MID/RIGHT representation.
  - Composite tokens (mid-left, mid-right) preserve nuance without visual clutter.

5.2 Conservative Distance Using Lower Band
  - Depth sensors can underestimate distance when sampling upper body surfaces; focusing on foot/ground adjacency improves collision risk estimation.

5.3 Single-Sentence Caption Constraint
  - Reduces reading time and working memory demands for mobility contexts; ensures atomic guidance.

5.4 Human-Readable Tokens
  - Avoids technical lane codes; fosters trust and reduces training overhead for end-users (e.g., elderly or clinical staff).

5.5 Deterministic Suggest + Model as Compressor
  - The VLM refines phrasing but does not decide movement—prevents unsafe emergent suggestions outside validated token set.

6. NOVEL CONTRIBUTIONS (PhD FRAMING)
------------------------------------
(1) Hybrid Deterministic–Generative Guidance: Architecture where spatial safety reasoning is formalized pre-generation; the VLM acts solely as a semantic compressor.
(2) Lane Abstraction with Composite Tokens: Mid-left/right combos represent multi-lane clearance states efficiently, balancing expressivity and cognitive load.
(3) Conservative Lower-Band Depth Metric: Empirical approach prioritizing ground-contact area for safer proximity assessment.
(4) Linguistic Safety Normalization: Post-generation filters to eliminate contradictory advisories (STOP+continue) and enforce risk-dependent detail inclusion.
(5) Mirrored Semantic Consistency: Dynamic re-mapping for mirrored video ensuring perceptual-linguistic alignment—crucial for adaptable camera setups.
(6) Caption Minimalism for Assistive Mobility: Tailored one-sentence safety guidance integrating symbolic lane decision and obstacle context under risk.

7. EVALUATION FRAMEWORK
-----------------------
Metrics:
  - Latency: Frame capture → caption time (ms); target sub-500 ms at 2 Hz processing.
  - Distance Accuracy: Compare lower-band median vs true measured distance (laser or ground truth markers) across object classes.
  - Suggest Correctness: Agreement rate between algorithm Suggest and expert-labeled safe action per scene.
  - Advisory Precision/Recall: Classification performance for SAFE/CAUTION/STOP vs incident ground truth.
  - Cognitive Load: NASA-TLX scores in user trials with vs without single-sentence constraint.
  - Trust & Clarity: Likert-scale user ratings on interpretability.
Experimental Setup:
  - Controlled corridor with varied obstacles (static/dynamic).
  - Ground truth capture via motion tracking or manual annotation.
  - Ablation: full system vs versions without lower-band depth, without composite lane tokens, without post-processing normalization.

8. LIMITATIONS
--------------
  - Fixed threshold may underperform across diverse environments (narrow vs wide corridors).
  - YOLOv8 nano may miss small/thin obstacles (e.g., cables) affecting advisory reliability.
  - Depth median ignores temporal smoothing; transient noise can induce clearance flapping.
  - Reliance on accurate RealSense alignment; extreme lighting or reflective floors degrade depth stability.
  - VLM summarization can still produce occasional lexical variants requiring fallback normalization.

9. FUTURE WORK
--------------
  - Adaptive & probabilistic thresholds using rolling quantiles and uncertainty (depth variance).
  - Temporal filtering of lane medians (exponential smoothing) to reduce jitter.
  - Multi-modal fusion (IMU, wheel encoders) to contextualize movement intent.
  - User-adaptive language generation (personalized vocabulary simplification).
  - Integrate lightweight on-device fine-tuning for specialized obstacle classes (e.g., medical equipment).
  - Safety certification process (formal verification of Suggest rule-set invariants).

10. CONCLUSION
--------------
The Qwen VLM solution embodies a principled division of labor: deterministic spatial safety reasoning coupled with constrained natural language rendering. This hybrid minimizes generative risk in assistive navigation while maintaining human-centered clarity. Its contributions around conservative depth modeling, composite lane abstraction, and caption safety normalization advance the reliability and usability of multimodal guidance systems suitable for real-world mobility aids.
